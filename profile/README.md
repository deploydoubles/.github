# Deploy Doubles

**Deployed is not the same as working.**

An open standard and a set of reference apps for answering one question: *did this deploy actually work?*

```sh
npx deploydoubles verify https://your-deploy.example --commit <deployed sha> --json
```

- **[deploydoubles.dev](https://deploydoubles.dev)** — the site, and the catalog of doubles
- **[deploydoubles/doubles](https://github.com/deploydoubles/doubles)** — the specification, the verifier, the check libraries and the reference apps
- **[Specification](https://github.com/deploydoubles/doubles/tree/main/spec)** — the report an app serves about itself, the manifest, and the outside checks

Authored by Jan Peter Wiersma and built openly with AI agents under his direction and review.
